⌨️ Typing Speed Tester
A simple and elegant Command Line Typing Speed Testing application built with Python. It helps users measure their typing speed (WPM), track accuracy, test themselves with dynamic word prompts, and practice under customizable session time limits.

✨ Features
⏱️ Custom Time Limit Selection (15s, 30s, 60s)

🎲 Continuous Dynamic Word Prompts

📊 Real-time WPM (Words Per Minute) Calculation

🎯 Accuracy Percentage Tracking

📝 Detailed Performance Results Summary

⌨️ Standardized Character-Based WPM Metric

🎨 Clean and Interactive CLI Interface

🛠️ Built With
Python

Standard Libraries (random, sys, time, select)
